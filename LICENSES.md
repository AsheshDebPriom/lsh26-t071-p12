## Starters, templates and UI kits

| Material | Licence | Notes |
|---|---|---|
| `create-next-app` scaffold | MIT | Generated **during the event** with `npx create-next-app@latest` (TypeScript, Tailwind, ESLint, App Router, `src/`). The generated `page.tsx`, `layout.tsx`, `globals.css` and placeholder SVGs were all replaced or deleted. |

No UI kit, component library, theme, icon set or CSS template was used. Every
component in `src/components` was written for this project. The interface uses no
icon font and no imported icons — the few glyphs on screen (`▲ ▼ ↑ ↓ ৳ ×`) are
Unicode characters.

`shadcn/ui` was named in the brief's stack. It was not installed: the six
primitives this app needs (`Button`, `Input`, `Select`, `Card`, `Pill`, `Sheet`)
were written directly in `src/components/ui.tsx` and `Sheet.tsx`, which is what
copying them from shadcn would have produced anyway, without adding Radix and
`class-variance-authority` to the tree for six components.

## Data

| Material | Source | Notes |
|---|---|---|
| `public/sample-data/P12_personal_ledger_public.json` | LofiStack Hackathon 2026 participant pack | The 25 published P12 cases, committed **unmodified**. Shipped so judges can load any of them in the app. |
| `src/lib/seed.ts` | Derived from the above | Case PUB-01 converted to integer paisa, used as first-run data. Generated from the fixture, not hand-written. |

The shop names in the fixture (Meena Bazar, DESCO, bKash, Pathao and so on) are
real Bangladeshi businesses named in the organisers' sample data. They are used
only as data values and no affiliation is implied.
